# 安装完成后的对话说明

在执行安装的当前对话中主动说明，并按真实检查结果填写：

“安装完成。桌面已创建企鹅图标的 **Qdex 2007** 快捷方式。
双击它启动；首次默认 QQ，右上角可切换原生/QQ，以后记住上次选择。
QQ 模式的竖长窗管理项目和对话；双击对话打开横向聊天窗，‘新聊天’创建空白聊天。
模型、附件、听写等在输入框上方，右下角发送，完成时使用 QQ 咳嗽声。
从原来的 Codex 入口打开仍是原版；Qdex 启动器负责自动加载皮肤，不是 Windows 开机自启动。
想恢复时，可选原生；完整回退可退出 Qdex 并打开原版 Codex。原版程序和聊天数据保留。”

不要把未测试的声音设备、发送、上传、多屏或长时间稳定性写成通过。独立运行安装脚本只会打印这份说明；通过 Skill 安装时由助手在对话里说明，不自动向其他聊天发送消息。
